# Bot-KSR

Минимальный Telegram-бот для формирования выгрузок из Anketolog по двум программам.

## Что делает бот

После любого сообщения бот показывает две inline-кнопки:

- `Культурно-просветительская лекция для студентов 2026 год`
  - формирует и отправляет выгрузку по анкете `Культурно-просветительская лекция для студентов  2026 год`
  - ищет анкету в папке `Мои анкеты/Академия Меганом 2026/КСР/Лекции для студентов (вузы)`
- `Культура мастерства 2026`
  - формирует и отправляет две выгрузки:
    - `Культура мастерства до программы 2026`
    - `Культура мастерства итоговый 2026`
  - ищет анкеты в папке `Мои анкеты/Академия Меганом 2026/КСР/Культура мастерства`

## Настройка

```bash
cd Bot-KSR
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN="telegram_bot_token"
ANKETOLOG_TOKEN="anketolog_api_token"
ALLOWED_USERNAMES="username1,username2"
PROXY=""
```

Доступ к боту разрешен только пользователям из allowlist. Username можно указать в `.env`
через запятую или в `config/allowed_usernames.json`:

```json
[
  "username1",
  "@username2"
]
```

Если список пустой или у пользователя Telegram не задан username, бот не даст доступ.

Прокси можно настроить через `.env`:

```env
PROXY="socks5://user:password@host:port"
```

Или через локальный файл `PROXY.py` на основе `PROXY.example.py`:

```python
PROXY = "socks5://user:password@host:port"
```

`PROXY.py` не попадает в git. Через этот прокси идут запросы к Telegram Bot API
и запросы к Anketolog.

## Запуск

```bash
python main.py
```

Скачанные файлы временно сохраняются в `downloads/`, отправляются пользователю в Telegram
и сразу удаляются с сервера. Статусное сообщение `Готово. Выгрузка отправлена.`
удаляется автоматически через несколько секунд.

Запросы выгрузок пишутся в `logs/export_requests.log`. В каждой строке есть время,
Telegram id, username, имя пользователя и точное название выгрузки, полученное из Anketolog.
